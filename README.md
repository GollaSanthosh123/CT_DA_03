# Task 3 – Dashboard Development

This project is part of my **Data Analyst Internship at CodeTech**. The goal of Task 3 is to design an **interactive dashboard** that presents insights from a dataset using **Power BI**.

## Task Objective

> Create a fully functional interactive dashboard using Power BI, Tableau, or Dash to visualize key metrics and insights from a dataset.

## Dataset

The dataset used is a synthetic Amazon-style product reviews dataset with the following columns:
- `review_id`: Unique ID
- `product_title`: Name of the product
- `review_body`: Review text
- `star_rating`: Rating from 1 to 5
- `customer_id`: Randomly generated
- `review_date`: Date of review

>  File: `sample_amazon_reviews.csv`

## Tool Used

- **Power BI Desktop**

## Visualizations Created

| Visualization Type | Description |
|--------------------|-------------|
|  **Bar Chart** | Count of reviews per product |
|  **Donut Chart** | Star rating distribution |
|  **Line Chart** | Number of reviews over time |
|  **Bar Chart** | Average rating per product |
|  **Table** | Top 10 most reviewed products |

## 🎛 Interactivity Features

- **Slicers** to filter by:
  - Product title
  - Star rating
- **Cards** to display:
  - Total number of reviews
  - Average overall rating

## Key Insights

- "Smart Watch" received the highest number of reviews.
- Most reviews are 4 and 5 stars, indicating positive customer satisfaction.
- Review activity peaks in certain months, showing engagement trends.
- Some products like "Bluetooth Speaker" maintain consistently high ratings.
